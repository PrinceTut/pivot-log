Most AI work doesn't need a thinker.

pivotjev.router puts a fast decision model in front of every task. Jev reads it, picks one of ten categories in about a third of a second, and only the work that needs real reasoning goes to the expensive model.

What's underneath.

The model is ten paragraphs.

There's no training on this side. Each category has a short description, and that text is what Jev reads when it decides. Fix a confusing description and the behaviour changes on the next call.

It fails upwards.

Low confidence, an error or an unknown answer all send the task to Opus. The router can overspend on a task. It can't quietly hand a hard task to the cheapest model.

Tested before it spent a cent.

Every rule was built and checked against fake answers first. 80 offline tests run on every push, and the code is open under an MIT licence.
